# 🚀 Darshan Dev Pack

> Complete frontend development toolkit for React, React Native, and modern web development.

---

## ✨ Features

Darshan Dev Pack provides a curated set of essential extensions to boost productivity and streamline development.

### ⚛️ Frontend & React

* React snippets for faster coding
* React Native development support
* HTML, CSS, and class name IntelliSense

### 🎨 Styling & UI

* Tailwind CSS support
* Styled-components support
* Color preview and highlighting

### 🧹 Code Quality

* Prettier for automatic formatting
* ESLint for linting and error detection

### 🔧 Git & Version Control

* GitLens for advanced Git insights
* Git Graph visualization

### ⚡ Productivity Tools

* Auto import modules
* Path IntelliSense
* Auto rename & close tags
* Code snippets and helpers

## 🛠️ Installation

### From Marketplace

1. Open Extensions in VS Code
2. Search for **Darshan Dev Pack**
3. Click **Install**

### From VSIX

1. Open Extensions
2. Click `...` → Install from VSIX
3. Select the `.vsix` file
